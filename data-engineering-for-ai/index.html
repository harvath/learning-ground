Data Engineering for AI

Take all of an organization's data, then store it, describe it, govern it, make it reachable, and let an agent act on it — understood from foundations. One running example company (Meridian) threads through every lesson. Concepts first; tools shown as current examples, none crowned.

the spine Every lesson advances one segment of the same path: store → describe → govern → make reachable → act on. By the end you'll have conceptually built one governed retrieval pipeline over Meridian's data — enough to know what a real one demands.
